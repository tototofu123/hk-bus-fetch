# HK Bus Fetch

This project is a simple Hong Kong bus finder built with plain HTML, CSS, and JavaScript.

## About the implementation

The majority of the code and the core implementation were written by a human. AI was used to help with the CSS part and a few minor adjustments in the JavaScript code.

## Files

- `index.html` - page structure
- `styles.css` - custom styling
- `script.js` - bus search, geolocation, ETA, and recommendation logic

## Notes

- Uses the KMB API for bus data
- Uses browser geolocation for the user's current location
- Shows walking-time advice when the walk is longer than 20 minutes
